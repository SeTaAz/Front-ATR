# mi-proyecto

Frontend en React + Vite, gestionado con **pnpm**.

## Scripts

```bash
pnpm install   # instalar dependencias
pnpm dev       # servidor de desarrollo
pnpm build     # build de producción
pnpm preview   # previsualizar el build
```

## Features

Login, Roles, Usuarios, Repuestos, Agenda, Servicios, Entradas,
Dashboard, Empleados, Clientes, Ventas, Hoja de vida y Garantías.
